## 12. Non-Functional Requirements (NFRs)

### 12.1 Accessibility (WCAG 2.1 AA)
- **Contrast Ratios:** Minimum 4.5:1 for normal text and 3:1 for large text / UI components.
- **Keyboard Navigation:** Full page navigability using `Tab` and `Shift+Tab`. Visible focus indicators (`outline: 2px solid #0284c7; outline-offset: 2px;`) on interactive elements.
- **Screen Readers:** Semantic HTML markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<h1>`-`<h3>`). All non-decorative images must feature descriptive `alt` tags.
- **Reduced Motion:** Respect `prefers-reduced-motion: reduce` media query by disabling parallax effects and smooth scrolling animations.

### 12.2 Performance & Technical Quality
- **Core Web Vitals:**
  - Largest Contentful Paint (LCP): < 2.5 seconds.
  - First Input Delay (FID) / Interaction to Next Paint (INP): < 200 ms.
  - Cumulative Layout Shift (CLS): < 0.1.
- **Asset Size:** Total initial page download payload < 1.0 MB. Zero heavy JS frameworks unless required.

### 12.3 Privacy & Data Governance
- **Zero Sensitive Data:** No patient records, clinical raw data, or confidential employer data.
- **De-identification:** Synthetic or anonymized data only for future project demos.
- **Location Transparency:** Public listing of "Lagos, Nigeria" subject to confirmation.

### 12.4 Security & Maintainability
- Static file delivery via GitHub Pages HTTPS.
- No dynamic server-side scripts or database dependencies.
- Code base formatted via Prettier and linted via ESLint / HTMLHint.
